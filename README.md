# Perinatal Health Surveillance Reporting Pipeline

A full‑stack business intelligence project built in response to a **Reporting Analyst** role at **BORN Ontario**.  
It ingests raw CDC Natality data, models a star‑schema data warehouse in PostgreSQL, performs epidemiological analysis with R and SAS, and delivers an interactive Power BI dashboard.

## Data Source
CDC Natality Public Use File (2022), accessed via NBER.  
500,000 live‑birth records, stratified by preterm status.

## Tools Used
- **R & R Markdown** – statistical analysis, automated reporting
- **SAS (OnDemand for Academics)** – cross‑validation of key metrics
- **PostgreSQL** – data warehouse with star schema
- **Power BI** – interactive dashboard
- **Git & GitHub** – version control
